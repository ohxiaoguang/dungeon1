# Dungeon1 操作说明（macOS / iOS / iPadOS）

本说明介绍 **Dungeon1 移植版**（游戏版本 1.3.0）在 Mac、iPhone 和 iPad 上的操作方法。

这是一份针对本移植版本的操作说明。本版本为了让触屏与鼠标能玩这款原本为手柄和鼠标设计的游戏，增加了若干自己的操作方式，因此部分操作与 Switch 原版或其他平台**并不相同**。文中凡标注「待验证」的内容，表示尚未在真机上完成最终确认。

当前版本提供以下操作方式：

| 平台 | 操作方式 |
|---|---|
| iPhone / iPad | 虚拟手柄（默认）、直接触控、虚拟触控板 |
| Mac | 鼠标、MacBook 触控板（含双指滑动） |
| 两个平台 | 支持通过系统配对的实体手柄（蓝牙或有线） |

操作方式在**启动器**里选择，进入游戏后不能切换；想换方式请退出游戏，在启动器里改好再进入。

---

## 1. iOS / iPadOS：虚拟触控板

虚拟触控板把整块屏幕变成一块触控板：屏幕上会出现一个白色箭头（虚拟鼠标光标），用它去指游戏里的东西。

### 操作表

| 手势 | 功能 |
|---|---|
| 单指滑动 | 移动虚拟鼠标光标 |
| 单指轻点 | 在光标位置单击 |
| 单指连续轻点两次 | 在光标位置双击（游戏原生双击） |
| 单指停住约 0.5 秒 | 在光标位置向游戏按下，进入游戏自身的长按 |
| 双指一起滑动 | 向游戏发送原生触摸拖动（火炬、列表，也可搬动物品） |
| 双指松开 | 结束当前滑动或长按 |

### 必须知道的规则

- **手指的位置不是点击的位置。** 所有点击、滑动、拖拽都发生在**虚拟光标**所在的位置，与你手指按在屏幕的哪里无关。先把光标移到目标上，再操作。
- **单指移动不会按下游戏里的任何东西。** 单指只移动光标，不会产生游戏内的触摸按下，所以「光标停在饰品上 → 抬手 → 再滑动继续移动」不会把饰品拿起来。
- **单指停住会变成游戏的长按。** 手指按在屏幕上不动约 0.5 秒，本版本才会在光标处向游戏按下；再继续按住约 0.5 秒，游戏自己的长按（按住购买、按住切换技能等）就会生效。所以完整的长按大约需要按住 1 秒。按下期间箭头变成**橙色**。
- **长按过程中移动会取消。** 一旦在光标处按下，手指再明显移动就取消这次按下（光标保持原位），不会变成拖拽。
- **没按满就松手会被取消。** 如果游戏还没来得及把它当作长按就松手，这次按下会被撤回，不会变成一次点击。
- **双指滑动是一段真实的游戏触摸。** 游戏会把它当成一根手指在屏幕上按下并拖动，所以光标会跟着这段触摸一起移动，滑动时箭头变成**蓝色**。
- **双指滑动也能搬动物品。** 因为游戏把它当作手指拖动，当光标正停在可拖动的物品上时，双指滑动会把该物品拖起来——**不需要先停顿**，直接滑动即可。
- **不是所有界面都支持双指滑动。** 能响应滑动的通常是列表、卷轴和火炬这类可拖动区域；某些面板不接受滑动，需要改用其他方式（例如手动拖动滚动条）。
- **双指或长按都不会产生点击。** 松手也不会补一次点击。

### 示例 A：查看饰品信息

1. 单指滑动，把光标移到饰品上。
2. 停住，查看游戏的悬浮提示。
3. 想继续看下一件：抬手，再次单指滑动即可——不会把刚才那件饰品拿起来。

### 示例 B：点击与双击

1. 单指滑动，把光标移到目标上。
2. 单指轻点一次，等于在光标处单击。
3. 快速连续轻点两次，等于游戏原生双击（例如打开角色详情）。

### 示例 C：搬动物品

1. 单指把光标移到要拖动的物品上。
2. 双指一起移动（可以直接移动，不必停顿），物品被拖动，箭头变为蓝色。
3. 松开任意一根手指即放下。

### 示例 C2：商店里按住购买

1. 单指把光标移到商品上，轻点让它聚焦。
2. 单指停在原地约 0.5 秒，本版本在光标处向游戏按下（箭头变橙色）。
3. 继续按住约 0.5 秒，游戏自己的长按生效。
4. 松手完成这次操作；中途移动会取消。

### 示例 D：火炬滑动

1. 单指把光标移到火炬的操作区域。
2. 双指直接向下滑动（不需要停顿）。
3. 游戏收到一段向下的原生触摸拖动。

> **设备验收**：本轮虚拟触控板的单指长按、统一双指滑动及模式切换设置重置已由用户验证通过。火炬沿用游戏自身的触摸拖动逻辑。

## 2. iOS / iPadOS：直接触控

直接触控把整块屏幕交给游戏自己处理，不显示虚拟手柄，也没有虚拟光标。

- **切换方法**：启动器 → **操作方式** → **直接触控** → 开始游戏。
- **点击与滑动**：手指按在屏幕哪里，就作用在哪里；轻点、拖动、长按的含义完全由游戏决定，与 Switch 掌机模式的触摸一致。
- **长按**：长按是否有效取决于「触控策略」开关（见下）。

**触控策略**（默认关闭，位于「直接触控」这一项下方）是本移植版给游戏追加的一组长按行为：

| 场景 | 开启触控策略后 |
|---|---|
| 战斗 / 扎营技能 | 按住可切换 |
| 游商马车（金币页与 DLC 页） | 轻点聚焦，按住 0.5 秒后松手执行一次购买 |
| 城镇英雄头像 | 按住 0.5 秒后松手打开详情 |
| 公会·技能（解锁与升级） | 轻点只聚焦（显示名称、价格与说明），按住 0.5 秒才执行一次购买 |
| 铁匠铺·武器 / 护甲升级 | 轻点查看，按住至少 0.5 秒后松手执行一次升级 |
| 扎营训练师·技能、城镇建筑升级树 | 轻点查看，按住至少 0.5 秒后松手执行一次购买 |

这些扩展只识别经过版本及回调类型校验的升级树；其他普通菜单保持原行为。初次解锁使用控件绑定类型识别，即使该条目尚未显示过说明也适用。公会初次解锁与后续升级、铁匠铺、扎营训练师和建筑升级已由用户完成设备验收；自动化检查作为补充。
按住后如果手指明显移动、或用第二根手指、或被系统取消，都不会购买；同一次按住最多只会买一次。

关闭时就是游戏原本的触摸行为。该开关只在「直接触控」这一项下显示；切换操作方式时它会被关闭，避免在别的模式里悄悄生效。

**与虚拟触控板的区别**：直接触控没有光标，点击落在手指上，长按立刻生效；虚拟触控板用光标定位，长按也能用，但要先把光标停在目标上，并且多等约半秒才向游戏按下。

## 3. iOS / iPadOS：虚拟手柄

虚拟手柄在游戏画面之上叠加一组按键，位置与 Nintendo Switch 手柄对应。

### 三种布局

屏幕顶部中央有一个显示当前布局的小按钮（`2D` / `3D` / `Tap`），点它按 **2D → 3D → Tap** 的顺序切换；选择会被记住。

| 布局 | 内容 |
|---|---|
| **2D** | 基础手柄：左上 ZL / L，右上 ZR / R，顶部中间 − 与 +，左下左摇杆，右下 A / B / X / Y |
| **3D** | 在 2D 基础上增加十字键、L3 / R3，并可选显示右摇杆 |
| **Tap** | 只保留顶部中央的布局按钮，其余触摸全部交给游戏（适合本来就靠触摸玩的界面） |

- 按键按 **Nintendo 位置**排列：右侧 A、下方 B、上方 X、左侧 Y。
- 左摇杆是固定圆环，从圆环中心量取倾斜方向，有少量死区。
- 在 3D 布局中，落在屏幕右侧三分之一、且没有压到任何按键的手指，会按住右摇杆。
- 实体手柄随时可用；接上实体手柄时虚拟手柄会自动隐藏，但不影响你的布局选择。

### 这一项下的两个开关

- **禁用触摸**（默认关闭）：开启后，游戏不再收到普通触摸输入；虚拟手柄本身、它的三种布局以及实体手柄都照常工作。适合「只想用手柄、又怕误触屏幕」的情况。
- **触控反馈**（在「高级」里，默认关闭）：按下虚拟手柄按键时给出轻微振动。

## 4. macOS：鼠标和触控板

| 操作 | 行为 |
|---|---|
| 移动鼠标或触控板指针 | 移动游戏光标（悬浮、提示随之更新） |
| 单击（左键） | 点击 |
| 双击 | 游戏原生双击 |
| 按住鼠标左键移动 | 拖拽 |
| MacBook 触控板按下并移动 | 拖拽（与按住左键相同） |
| 触控板双指滑动 | 转换为游戏的原生触摸滑动（火炬、列表） |

需要注意：

- **双指滑动不是鼠标滚轮。** 游戏本身不读取鼠标滚轮，所以本版本把双指滑动**适配成一段游戏触摸**（从鼠标指针处按下并拖动），而不是发送滚轮事件。
- 这项适配**只在 Dungeon1 上、并且「实验性鼠标控制」开启时**生效（该开关默认开启）。
- **不影响原有的鼠标操作**：鼠标左键的点击、按住拖拽、悬浮提示和实体手柄输入都保持原样。按住左键期间双指滑动不会介入；开始按住左键会立即结束正在进行的双指滑动。
- **方向跟随你的系统「自然滚动」设置**：手指向下滑，游戏里的拖动就向下。
- 惯性滚动（手指离开触控板后的滑行）不会被送进游戏，松手即结束，不会出现「手指已经离开、物品还在被拖」的情况。
- **并非所有列表都能用双指滑动滚动。** 饰品仓库这类界面建议**手动拖动滚动条**。
- 触控板的「双指滑动」与「按下并移动」是两种不同操作：前者送出一段触摸拖动，后者等同于按住鼠标左键拖拽。

## 5. 启动器设置说明

### iOS / iPadOS

| 设置 | 说明 | 默认 |
|---|---|---|
| 操作方式 | 虚拟手柄 / 直接触控 / 虚拟触控板 | 虚拟手柄 |

| └ 触控策略（实验性） | 仅「直接触控」下显示：追加长按行为（见第 2 节） | 关闭 |
| └ 指针速度 | 仅「虚拟触控板」下显示：0.5×–2.0×，每档 0.1×，只影响光标移动快慢 | 1.0× |
| 主机模式 | 底座模式 / 掌机模式 | 掌机模式 |
| 界面语言 | 启动器与游戏内界面语言 | 跟随系统 |
| 高级 → 游戏振动 | 手机或手柄的振动 | 关闭 |
| 高级 → 振动强度 | 仅在游戏振动开启时显示 | 1.0 |
| 高级 → 显示帧率 | 左上角帧率数字 | 关闭 |
| 高级 → 性能面板 | Apple 的性能叠加层 | 关闭 |
| 高级 → 触控反馈 | 按下虚拟手柄按键的振动 | 关闭 |
| 高级 → 在 3D 模式显示右摇杆 | 仅影响 3D 布局的显示；未使用虚拟手柄时该项不可改（已保存的值会保留） | 关闭 |

「高级」默认折叠，点整行（标题、空白或箭头）都可展开。

**切换操作方式会重置子选项。** 换到另一种方式时，新模式的三项子设置都会回到默认值：禁用触摸关闭、触控策略关闭、指针速度 1.0×。这样上一种方式留下的设置不会在新方式里悄悄生效。只有你**真的换了方式**才会重置——打开启动器、或者重新选择当前这种方式，都不会改动你已经调好的子设置（这些设置本身仍会照常保存）。

**操作方式右侧的问号按钮**：点开可以看到当前模式的简明操作说明，也可以在里面切换到另外两种模式查看，随时关闭，不影响启动器布局。

## 6. 已知限制

- **双指滑动不是通用鼠标滚轮。** 它是被适配出来的一段游戏触摸，只有游戏本身支持拖动/滑动的地方才有效。
- **饰品仓库等列表可能滚不动**，请手动拖动滚动条。
- **虚拟触控板的长按要按满约 1 秒**：其中 0.5 秒用来让本版本在光标处按下，另外 0.5 秒是游戏自己的长按判定。按不满就松手会被取消，不会变成点击。
- **双指滑动在可拖动物品上会触发游戏原生拖动**，这是游戏自身的行为，不是误操作；不想拖动时，把光标停在物品旁边再滑动。
- **不同硬件的振动能力不同**：iPad 通常没有 iPhone 那样的触感马达，游戏振动主要靠支持振动的手柄；触控反馈属于界面层的轻微振动，同样取决于设备。
- Mac 上双指滑动的灵敏度与手感由游戏内的拖动距离决定，本版本没有单独的灵敏度设置。

## 7. 常见问题

**为什么单指移动不能拖动物品？**
因为虚拟触控板的单指只移动光标，不向游戏发送触摸。这正是为了避免「光标停在物品上、再碰一下屏幕就把它拿起来」。要拖动请用双指。

**怎样拖动物品？**
把光标移到物品上，双指一起移动即可（不需要停顿），物品会跟随光标；松开任意一根手指放下。

**双击怎样操作？**
把光标移到目标上，快速连续轻点两次。游戏会按它自己的双击规则处理（与手指直接双击相同）。

**为什么双指滑动不能滚动某些列表？**
游戏只在自己支持拖动的区域响应滑动。列表类界面如果不动，请手动拖动滚动条；部分面板需要先选中再翻页。

**如何降低火炬亮度？**
把光标移到火炬的操作区域，双指向下滑动。若没有反应，请先确认光标确实停在火炬上（箭头就是游戏指针的位置）。

**为什么长按要按比较久？**
在虚拟触控板模式下，手指要停住约 0.5 秒，本版本才会在光标处向游戏按下，游戏自己的长按判定还要再花约 0.5 秒，所以完整长按大约 1 秒。需要立刻生效的长按（按住购买、按住切换技能）可以改用**直接触控**，并确认「触控策略」已开启。

**长按之后松手，会不会变成一次点击？**
不会。若游戏还没来得及把它当作长按，本次按下会被撤回；已经在游戏中生效的长按则由游戏按自己的规则结束。

**Mac 触控板怎样进行拖拽？**
两种都可以：①按住触控板并移动（等于按住鼠标左键）；②双指滑动（送出一段游戏触摸拖动）。前者用于常规拖拽，后者用于列表和火炬这类需要滑动的区域。

**如何切换到直接触控模式？**
退出游戏 → 启动器 → **操作方式** → **直接触控** → 开始游戏。选择会被记住。

**为什么 iPad 上没有振动？**
先确认「高级 → 游戏振动」已开启。即使开启，iPad 通常也没有触感马达，振动主要由支持振动的手柄提供；「触控反馈」是界面按键的轻微反馈，同样取决于设备。

**指针速度会影响点击位置吗？**
不会。它只改变光标移动的快慢，点击永远发生在光标所在处。
